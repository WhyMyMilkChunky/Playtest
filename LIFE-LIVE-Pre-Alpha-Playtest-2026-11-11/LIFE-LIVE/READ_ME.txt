LIFE//LIVE - PRE-ALPHA PLAYTEST - Windows x64 Release build

Extract the entire LIFE-LIVE folder before playing. Double-click LIFE-LIVE.exe.
Keep LIFE-LIVE.exe, the DLLs and the assets folder together in a writable folder.
Visual Studio, vcpkg and the Vulkan SDK are not required. This package uses OpenGL.
No command script, installer or administrator privileges are needed.

This pre-alpha executable is unsigned. Windows SmartScreen may show an
unrecognized-publisher/reputation warning; a Release build does not establish
publisher trust or download reputation. Report any named antivirus detection
separately, including its exact threat name.

Controls: WASD move, mouse look/fire, E interact, R reload, Shift sprint,
Ctrl crouch/slide, Space jump, Tab dossier/inventory, Esc pause, F11 fullscreen.
Controller: left stick move, right stick look, L3 toggle sprint (stopping forward
movement cancels), R3 crouch/slide, Cross/A jump, Square/X interact or reload,
Triangle/Y next weapon, LT aim, RT fire, D-pad up flashlight, View/Back dossier,
Start pause, Circle/B back. In the store, Square/X marks items for sale and
Triangle/Y reviews the marked sale. ADS reduces controller look sensitivity.
Ctrl+P opens dungeon tools. Under Dungeon generation, enable Force floppy-disk
puzzle and press Regenerate seed to generate a dungeon containing the disk lock.

This contains the optimized game executable, runtime data, game textures,
models, audio, runtime shaders and app-local Visual C++ runtime DLLs.
Texture authoring sources, Blender files, code, editor executables, development
tools, build intermediates, caches, debug symbols and personal settings are omitted.
Runtime shader text and OBJ meshes are required game assets.

PACKAGE_MANIFEST.csv records SHA-256 hashes for every payload file.
